# IRAN GOLD — کلاینت چندموتوره‌ی VPN برای اندروید (GPLv3)

اپ اندروید با **یک** VpnService/TUN: `برنامه‌ها → TUN → hev-socks5-tunnel → موتور فعال (SOCKS5 محلی) → اینترنت`.
موتورها هرگز VPN نمی‌سازند؛ هر کدام فقط یک SOCKS5 روی 127.0.0.1 باز می‌کنند.

## موتورها
| موتور | وابستگی | وضعیت |
|---|---|---|
| Tor + Snowflake | مستقل (بدون سرور شخصی، بدون پرداخت) | در MVP |
| Xray (VLESS، REALITY/TLS/WS/gRPC…) | **کانفیگی که خودتان وارد می‌کنید** | در MVP |
| WARP / Psiphon / Geph / AmneziaWG | — | عمداً خارج از MVP (مجوز/شرایط استفاده یا ادغام تأییدنشده)؛ بعداً به‌عنوان موتور جدا |

## ویژگی‌ها
انتخاب خودکار موتور با امتیاز (۰–۱۰۰) از روی بررسی سلامت واقعی (TLS+HTTP، شناسایی captive portal، IP خروجی و نشت،
DNS راه‌دور، تأخیر، تست سرعت سبک) · circuit breaker · حافظه‌ی شبکه (بدون SSID/موقعیت) · نردبان ترمیم
(بررسی ← ری‌استارت ← تلاش مجدد ← تعویض موتور ← بازسازی مسیر) · کیل‌سوییچ · رابط Compose فارسی/RTL.

## امنیت
بدون MITM، بدون CA/گواهی جعلی (تأیید گواهی و hostname همیشه روشن؛ `allowInsecure` رد می‌شود) · کانفیگ‌های واردشده با
Android Keystore (AES-256-GCM) ذخیره می‌شوند و از طریق stdin به Xray می‌روند (روی دیسک نمی‌نشینند) · هیچ کلید/سرور
مشترکی داخل APK نیست · لاگ‌ها redact می‌شوند · IPv6 داخل TUN گرفته و دور ریخته می‌شود · مجوزها: INTERNET،
ACCESS_NETWORK_STATE، سرویس پیش‌زمینه، اعلان.
کیل‌سوییچ داخل برنامه است؛ قفل کامل نیاز به «VPN همیشه روشن + مسدودسازی اتصال بدون VPN» در تنظیمات اندروید دارد.

## وضعیت راستی‌آزمایی (صادقانه)
**انجام و اجرا شده:** کامپایل ماژول `core` با kotlinc واقعی و **۴۸ تست پاس‌شده** (از جمله SOCKS5 و TLS محلی، رد گواهی نامعتبر،
تشخیص نشت، مدار breaker، کنترلر و نردبان ترمیم) · کانفیگ تولیدشده با **خود Xray v26.9.9** (`run -test`) معتبر شد و با stdin
بدون فایل‌های geo اجرا و پورت SOCKS را باز کرد · کد غیر-Compose اپ با android-34.jar تایپ‌چک شد.
**انجام نشده:** ساخت APK (در محیط من Gradle/Maven/Google مسدود است) · کامپایل Compose UI، `Gold.kt` و `SnowflakeBridge.kt`
(نیازمند وابستگی‌ها) · هر آزمون روی گوشی واقعی یا شبکه‌ی ایران. مختصات `IPtProxy:5.7.0` و `tor-android:0.4.8.16` اینجا قابل دریافت نبود؛
اگر نسخه‌ای وجود نداشت، در `app/build.gradle.kts` عوض کنید. مقادیر Snowflake از torrc رسمی گرفته شده و ممکن است کهنه شوند.
**هنوز APK وجود ندارد.**

## ساخت APK
1. **GitHub Actions:** پروژه را در یک مخزن خودتان بگذارید ← Actions ← `build-apk` ← Run. خروجی: `IRAN-GOLD.apk` و `SHA256.txt`.
2. **Android Studio:** `./scripts/fetch-engines.sh` را اجرا کنید (نیاز به bash/curl)، پوشه را باز کنید، Build ← `assembleRelease`.
خطاهای کامپایل احتمالی (بخش «انجام نشده») در همین مرحله ظاهر می‌شوند.
APK نسخه‌ی release با کلید debug امضا می‌شود (برای نصب مستقیم، نه فروشگاه).
